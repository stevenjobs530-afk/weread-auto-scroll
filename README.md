# 微信读书自动滚动

简体中文 | [English](README.en.md)

让书页按你的节奏缓缓滚动。一款适用于 **微信读书网页版**的 Chrome 扩展，支持 **20 档速度、键盘调速、回车开始／暂停**，并提供贴边进度细条、玻璃质感按钮和中文使用说明。

**当前版本：1.4.3 · 无需注册 · 无统计追踪 · 无外部依赖**

## 安装方法

1. 从 [发布页面](https://github.com/stevenjobs530-afk/weread-auto-scroll/releases/latest) 下载 `WeRead-Auto-Scroll.zip`，或点击仓库的 **Code → Download ZIP**。
2. 解压到一个方便保留的位置，安装后不要删除或移动该文件夹。
3. 在 Chrome 地址栏输入 `chrome://extensions`，打开右上角的「开发者模式」。
4. 点击「加载已解压的扩展程序」（Load unpacked），进入解压后的文件夹，选择其中的 **extension** 子文件夹。
5. 确认扩展版本为 **1.4.3**，然后刷新微信读书的阅读页面。

**必须选择包含 `manifest.json` 的文件夹，不是外层文件夹，也不是 ZIP 文件。** 如果提示「清单文件缺失或不可读取」，请再进入一层，选择 `extension`。

```text
weread-auto-scroll/
├── README.md
├── LICENSE
└── extension/          ← 选择这个文件夹
    ├── manifest.json
    ├── content.js
    └── scroll-core.js
```

本扩展尚未上架 Chrome 应用商店，需手动加载。适用于电脑端 Chrome，以及微信读书中可纵向滚动的阅读页面。

## 快速上手

打开一本书，页面左侧会出现 **48 像素宽**的进度细条。按 **S／回车键（Enter）**或点击 **▶** 开始滚动；点击百分比、档位或 **⚙** 展开设置，可查看完整中文说明。默认暂停、默认收起。

| 操作 | 效果 |
| --- | --- |
| **S 或回车键（Enter）** | 开始／暂停 |
| **A** | 立即减慢 1 档，最低 1 档 |
| **D** | 立即加快 1 档，最高 20 档 |
| **1～9** | 等待 0.5 秒后设为对应档位 |
| 快速依次按 **1、5** | 设为 **15 档** |
| 快速依次按 **2、0** | 设为 **20 档** |
| 快速依次按 **1、0** | 设为 **10 档** |
| 单独按 **0** | 等待 0.5 秒后设为 **10 档** |
| **Esc** | 暂停，并取消尚未生效的数字 |
| 拖动滑块 | 立即选择 1～20 档 |
| 拖动细条顶部点阵 | 上下移动；拖至另一侧可切换贴靠方向 |
| 点击 **−**／百分比、档位、齿轮 | 收起／展开设置 |

A、D 每按一次调整一档，长按不连发。当前 5 档时，按 A 的结果是 4、3、2、1；到 1 后不再减小。W 暂不绑定功能。调速不改变滚动状态，尚未确认的数字会先应用再加减。输入框、输入法组词和修饰键组合仍不触发这些快捷键。

### 怎样输入两位数？

例如设置 **15 档**：先按 **1**，在 **0.5 秒内**再按 **5**。面板会显示「正在输入」，两位数有效时立即生效，不会先切到 1 档。

如果两次按键相隔超过 0.5 秒，会分别生效：先设为 1 档，再设为 5 档。输入 **25、99** 等超出 1～20 范围的数字，会显示提示并保留原速度。

调速本身不会自动开始滚动。数字尚在等待时按 S 或回车，会先应用当前数字，再开始或暂停。长按按键不会反复触发。

在搜索框、笔记或其他输入框中打字，以及使用输入法组词时，快捷键不会生效。Command、Control、Option/Alt、Shift 组合键不受影响。焦点位于链接、滑块或其他按钮时，回车保留原有功能；如需控制滚动，先点击书页空白处。

## 阅读体验

- 速度从 1 档的 **每秒 5 像素**逐步增加到 20 档的 **每秒 200 像素**；默认 5 档，约每秒 11 像素。
- 手动滚动、点击书页和选择文字不会关闭自动滚动，也不会操作翻译功能。触控板手势期间暂时让出滚动控制，随后从新位置继续，避免跳回。到达底部或点击暂停／按 S、回车、Esc 才暂停。后台标签页暂时停止移动，返回后继续；刷新或切换章节仍默认暂停。
- 到达章节底部会显示「本章已结束」，不会自动跳到下一章。
- 速度和拖动后的位置保存在本地；刷新页面或切换章节后默认暂停。
- 面板适配浅色／深色背景；只有启用自定义版面后才会修改阅读区域。

## 贴边进度条与玻璃样式

细条固定在**网页可视区域**的左侧或右侧，靠近浏览器侧边栏；它不是 Chrome 原生侧边栏，也不需要额外权限。相较原 244 像素面板，默认宽度缩至 48 像素。设置按需展开，旧版速度和阅读区域偏好保留，旧版自由浮动位置不再使用。

- 进度按主文档 `scrollTop / (scrollHeight - clientHeight)` 计算，顶部显示 1%，到达底部显示 100%。这是当前页面的滚动位置，不是整本书的阅读完成率。
- 无可滚动内容时显示 100%；图片、懒加载或版面调整改变高度后会重新计算，进度可能降低。
- 滚动事件为被动监听，并合并到每个动画帧最多一次；只在整数百分比变化时更新界面。尺寸变化即时触发，特殊动态布局由已有的 400ms 页面检查补充。
- 多标签页各自计算进度和滚动状态；不在 iframe 内重复注入，也不统计 iframe 内部滚动。适用范围仍仅为微信读书阅读页。
- 按钮采用受 Apple Liquid Glass 启发的网页玻璃效果：半透明、背景模糊、高光边框、柔和阴影，保留绿色主色。不是苹果原生材质。支持深色背景；不支持背景模糊或启用减少透明度时使用实色后备样式。

## 竖屏／大屏阅读区域调整

展开面板中的「阅读区域调整」，勾选「启用自定义版面」。

- **阅读宽度：** 50%～95%，推荐先试 85%。按当前浏览器窗口宽度计算，并为两侧和工具栏预留空间；因此接近上限时，实际宽度可能小于设定百分比。
- **顶部留白：** 0～160 像素，位于网站顶部栏下方。减小它可以减少书页开头的空白。书籍内部的标题和插图间距仍由微信读书决定。
- **恢复默认版面：** 关闭自定义排版，恢复网站原有宽度和间距。

文字通过微信读书自身的排版过程重新换行，不会横向拉伸。章节的总高度随内容变化，仍然向下滚动，不会把整章压缩进一屏。调整后从新位置继续滚动，偏好保存在本地。插件面板本身可拖动或收起，避免挡住正文。

已在 1010 像素宽的真实微信读书窗口测试样式：85% 设置下正文从约 486 增至 808 像素，顶部栏和右侧工具栏未横向溢出。不同书籍、窄窗口或网站后续改版仍可能影响效果；遇到排版异常可恢复默认。新版控件的安装验证与样式测试是不同步骤。

## 更新与卸载

将新文件替换到 **Chrome 最初加载的那个文件夹**，再到 `chrome://extensions` 点击本扩展的 **↻ 重新加载**，最后刷新书页。

如果版本仍然显示旧版本，可能加载的是另一个解压副本。可以移除旧扩展，再重新加载新版 `extension` 文件夹。移除扩展可能重置已保存的偏好。

## 隐私与权限

仅申请 **storage** 权限，用于保存本地偏好；内容脚本只在 `https://weread.qq.com/web/reader/*` 页面运行。扩展会检查页面布局和章节标题来控制滚动，不收集或传输书籍正文、浏览历史、账号资料或使用统计。没有服务器，也不会下载外部代码。

本项目为独立工具，与腾讯或微信读书官方无关联；不提供解锁书籍或绕过访问限制的功能。

## 常见问题

- **看不到面板：** 直接打开一本书并刷新。仅打开书架不会注入扩展。
- **键盘没反应：** 确认已更新到 1.4.3，刷新书页，再点击书页空白处。
- **15 变成了 1 和 5：** 请在 0.5 秒内输入第二个数字。
- **滚动停止：** 到达底部或手动暂停后，需要再次开始。标签页在后台时不移动，返回后继续。
- 微信读书改版或其他扩展可能影响本工具。反馈问题时，请附上 Chrome 版本、扩展版本和复现步骤，避免公开账号信息或书籍正文。

## 开发与测试

无需构建或安装依赖。使用 Node.js 18 及以上版本运行：

```sh
node --test tests/core.test.cjs
node --check extension/content.js
```

本地预览需要 Python 3：

```sh
python3 tests/serve.py
```

打开 `http://127.0.0.1:8769/web/reader/preview`，按 Ctrl+C 停止服务。预览使用同一份扩展脚本，但用本地存储模拟 Chrome 存储；不能代替扩展安装和真实微信读书页面验证。

自动测试覆盖全部 20 档数字输入、等待／取消／非法输入、快捷键保护、小数位滚动与权限范围。GitHub Actions 在推送和拉取请求时运行检查。
